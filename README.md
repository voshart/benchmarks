# Voshart Benchmarks

This repository is initialized with the research and contributor instructions.

**Deployment status:** The complete Eleventy OCR scaffold has been prepared and locally tested, but its generated project files have not yet been committed to this repository. It will not build or deploy until those project files are uploaded.

To install the scaffold, extract the downloadable project ZIP shared in the accompanying ChatGPT conversation into the repository root, then commit and push its contents. Afterwards connect Cloudflare Pages using build command `npm run build` and output folder `_site`.

The OCR page is planned for `bench.voshart.com/ocr/`. See `AGENTS.md` for data editing and evidence rules.
